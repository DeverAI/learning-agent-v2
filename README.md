# 学习 Agent 操作说明

本文件是项目唯一的安装、启动与使用说明。产品架构见 [Design.md](Design.md)，实现细节见 [Techniques.md](Techniques.md)。

## 1. 环境要求

- Python 3.11 或更高版本
- Windows、Linux 或 macOS
- 至少一个可用 AI API Key；推荐同时配置视觉模型与推理模型
- SQLite 随程序使用，不需要另外安装数据库管理软件

项目面向低资源环境，日常运行不需要 Node.js、Redis 或 MySQL。大量并发 OCR、长文档解析和批量组卷仍会受 CPU、内存与模型接口速度影响。

## 2. 安装依赖

在项目根目录执行：

```powershell
python -m pip install -r backend/requirements.txt
```

如需使用独立虚拟环境，可先创建并激活环境，再安装同一依赖文件。

## 3. 启动与停止

从项目根目录启动：

```powershell
python -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload
```

浏览器打开 `http://127.0.0.1:8000`。开发调试保留 `--reload`；服务器长期运行时移除该参数，并由系统服务或进程管理器托管。

需要局域网访问时把 host 改为 `0.0.0.0`，并在防火墙中仅开放实际使用的端口。不要直接把开发服务器无鉴权暴露到公网。

停止前台服务：在启动终端按 `Ctrl+C`。

## 4. 首次配置

启动后打开 `/settings`：

1. 至少配置一个视觉模型：ZhipuAI 或 Kimi；默认优先使用智谱，失败时可回退小米 MiMo（mimo-v2.5，可选）再回退 Kimi。
2. 至少配置一个推理模型：DeepSeek，或为 `solve` 范围配置自定义兼容 API。
3. 可继续配置 Kimi、自定义 scope API 和唯一全局 fallback，覆盖分类、聊天或主模型故障。
4. 如需专注模式 AI 配音：在「小米 MiMo」卡片填入 Token Plan API Key（`tp-...`），选择音色并点击「试听配音」；未配置时自动使用浏览器合成。
5. 根据需要调整 token 上限、自动深色时间、强调色和其他可见设置。
6. 保存后打开 `/diagnose` 检查数据库、配置和服务状态。

设置页显示的是掩码 Key。留空保存会保留已有 Key，不要把真实 Key 写入文档或提交到版本库。项目 `backend/settings.json` 中显式保存的 Key 优先生效；工作区外层的共享 `api_keys.py`（api.txt）只在显式 Key 为空时作兜底。

## 6. 上传题目

上传前先选择唯一的上传模式：

- 每图一题：每张图片独立处理，适合连续拍摄多道单题。
- 多图一题：多张图共同构成一道题，上传后检查题干、解析、答案和其他图片角色。
- 自动分题：一张图片可能包含多题，系统先拆分，再逐题 OCR 和解答。

建议流程：

1. 选择模式和图片，可选填写学科、年级、知识点或解题提示。
2. 在暂存阶段检查缩略图；多图一题时修正图片角色。
3. 开始处理后等待状态从排队、OCR、生成答案进入完成。
4. 打开题目详情，核对原图、OCR 参考图、题面、标答、解析和得分点。
5. 点击“AI 质疑题目”可让独立解题 AI 主动检查条件矛盾、图文冲突、答案不唯一和参考答案错误；该操作不会自动改写题目。
6. 低概率疑点可在核对假设后继续使用；高概率问题题在人工确认前不会进入自动组卷、搜题匹配或批改。
7. 参考图失败或与原图不符时使用重试/编辑，不要只依据自动 SVG。

支持 JPG、PNG 和 WEBP。单文件前端限制为 10MB，后端会再次校验实际格式。手机浏览器可直接调用相机；桌面浏览器继续使用文件选择器。

## 7. 组卷

1. 打开 `/papers/generate`，选择学科、年级、题量、标签、纸张和 Prompt。
2. 提交后先查看题库容量提示。系统可能把自由组卷题量缩减到可用容量；固定题目不足时会停止。
3. 等待 AI 返回明确题目集合并完成卷面、答案和排版审查。
4. 在试卷详情核对题目顺序与分页后再下载。
5. “重新组卷”会重新选题；“重新排版”只调整当前题目集合。
6. 可保存组卷参数供以后复用，保存参数不等于保存当前题目 ID。

可按页面选项导出 A3/A4、试卷版、答案版或合并版。某种格式导出失败时，以页面实际返回的文件为准。试卷详情页支持按需勾选 `试卷 / 答案 / 得分点 / 答题卡` 多份下载，按 `试卷→答案→得分点→答题卡` 顺序分别触发；`答题卡` 缺失时由后端运行时合成。

## 8. 笔记与知识树

`/notes` 支持图片、TXT、Markdown、DOCX 和 PDF：

1. 上传后等待文本提取和结构化。
2. 检查学科、年级、知识点、标题、正文和典型题。
3. 同学科相近笔记可能自动合并；来源和原内容仍保留以便追溯。
4. 在知识树视图检查合并关系和题目引用。
5. 自动结果不确定时先人工修正，再让 Agent 或巡检继续整理。
6. “AI 生成笔记”会根据全部已完成题目归纳解题套路并生成/合并笔记；需要 AI 调用，耗时与题量相关。

本地知识库检索位于 `/qa`：先查已存文档，未命中时可让 GLM 联网搜索补充（需在设置页配置 GLM Key），检索结果自动存入知识库，可查看或删除。

## 9. 搜题与批改

搜题和拍照检查先选择范围，三种范围均可一次上传多张图（最多 12 张；单张 10MB；本次合计 60MB）：

- 单题：多张图属于同一道题或同一份作答，合并识别且只匹配一次。
- 单页：可上传页面全图和局部补充图，系统拆题后提供逐题搜题或检查汇总。
- 整卷：搜题按页序拆题；检查时必须先选择已生成试卷，再上传按页码排列的多页作答。

低置信度匹配不会自动绑定。整卷按题号和语义分段；若页序或题号模糊，先检查识别映射再接受结果。所有结果可在批改中心和历史页查看。

`/papers` 同时显示已生成试卷和未生成的整卷上传记录。上传记录显示“待上传、处理中、待生成、需处理”等状态；“需处理”表示存在失败、缺失或已锁定但未完成的题目，应进入上传记录或题库修复后再生成试卷。

## 10. 结构图与画布操作

题目详情中的结构梳理图保留生成、检查、重写、批注和查看入口：

- 滚轮：以光标为中心缩放。
- 拖拽：平移。
- 双击：重新适应完整图。
- 触屏单指：平移；双指：缩放。

实验图编辑器支持拖入组件、多选、移动、旋转、等比例缩放、层级、锁定、属性、语义摆法、校准、撤销/重做、图库和 SVG 导出。图库中保存的预设图可以加载，也可以从图库卡片上直接删除。工具栏“场景库”可浏览全部语义场景并按关键词搜索，同时逐对检查连接安全；“AI 插入元件”会在已加载的题目图上按描述插入新元件或标注（需要 AI 调用）。加载题目图统一走后端接口，若图不是最新会给出提示。常用快捷键：

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Delete` | 删除选择 |
| 方向键 | 移动 1px |
| `Shift+方向键` | 移动 10px |

输入框聚焦时，编辑器不会拦截这些键盘操作。

## 11. 专注模式

`/focus` 是 AI 驱动的专注学习空间，像一个真人老师那样教你：

1. 选择学习模式：输入一个主题、从题库选一道题、或混合模式。
2. AI 把知识拆成小段讲解，每段末尾输出「对吧」检查点。
3. 每次检查点自动采集你的语音回答和表情状态，生成情感报告。
4. AI 根据你的状态决定：继续下一段、换一种方式重述、插入练习、或暂停休息。
5. 学习记录自动保存到虚拟海马体，跨会话持久化你的认知状态。

讲解配音为双引擎：优先使用小米 TTS（`mimo-v2.5-tts`，需在设置页配置 Token Plan Key，可在「跟随配置/优先小米/仅浏览器」三种引擎间切换）；任何失败自动回退浏览器原生 SpeechSynthesis。语音识别使用浏览器 Web Speech API。表情分析使用摄像头截图 + GLM-4V-Flash 视觉模型（失败时回退小米 MiMo 或 Kimi）。

首次使用需授予麦克风和摄像头权限。浏览器不支持语音识别时自动降级为文本输入；浏览器不支持语音合成但配置了服务器配音时仍可正常朗读。

## 12. 首页组件与主题

首页点击“编辑组件”后可添加、移除、拖拽或前移/后移。保存后以服务端返回顺序为准；允许保存空首页，恢复默认需要手动点击对应按钮。

界面自动适配桌面、分屏、平板和手机，不是独立移动版。桌面仍保留侧栏和高信息密度，窄屏会重排、折叠导航并扩大触摸目标。业务颜色跟随设置中的强调色和明暗主题；实验图米白画布与黑白打印内容不跟随业务色变化。

## 13. 数据、日志与备份

- `backend/storage/`：数据库、题目、试卷、上传和生成文件。
- `backend/storage/hippocampus/`：虚拟海马体记忆数据（学习认知状态、掌握度记录）。
- `backend/storage/focus_sessions/`：专注模式会话数据（讲解片段、检查点响应）。
- `backend/settings.json`：本地设置与 API Key，请限制文件权限。
- `backend/Err.log`：运行时错误日志；出现失败时先查看该文件和 `/diagnose`。

备份时先停止服务，再复制数据库、`backend/storage/` 和 `backend/settings.json` 到项目外的受控位置。恢复前先保留现有数据副本。不要在服务运行中直接替换 SQLite 文件。

## 14. 常见排查

| 现象 | 检查 |
|---|---|
| 题目一直排队 | 查看 `/diagnose`、`backend/Err.log`、API Key 和模型名；重启后检查任务是否恢复 |
| OCR/解题无 JSON | 检查模型是否可用、token 上限与响应是否截断，再从题目页重试 |
| AI 401 | API Key 无效、过期或 Base URL/模型不匹配 |
| 公式不显示 | 检查浏览器控制台与 KaTeX 资源；刷新后仍失败再看前端错误日志 |
| 题目处理后“消失” | 将题库状态筛选改为“全部”，检查是否进入 error |
| 旧数据库缺字段 | 查看启动迁移日志；不要手工删除数据库，先备份并运行测试 |
| 结构图被裁剪 | 双击适应；若仍异常，检查 SVG viewBox 和题目结构图错误信息 |
| 导出缺少某格式 | 查看导出错误；只使用页面实际生成的路径 |
| 编辑器提示题目没有图片 | 在题目详情“示意图”页确认该题已有图；没有元件信息的旧图只能查看，重新保存后可编辑 |
| 试卷下载弹窗被浏览器拦截 | 浏览器对多次 `window.open` 严格策略可能弹拦截，请允许后重试，或按需勾选单份下载 |
| 桌面端侧栏消失 | 检查 `localStorage.sb_user_closed`：若被设为 `'true'`，刷新会保持收起；清除该值可恢复默认展开 |
| 专注模式无麦克风/摄像头 | 检查浏览器权限设置；确认网站已获得麦克风和摄像头访问权限；尝试刷新后重新授权 |
| 专注模式语音无法识别 | 检查浏览器是否支持 Web Speech API（Chrome/Edge 支持最佳）；检查麦克风是否被其他应用占用 |
| 讲解无声音（服务器配音） | 查看 `/settings` 小米卡片状态与浏览器控制台；确认 Token Plan Key 有效、`ENABLE_XIAOMI_TTS` 开启；配音失败会自动回退浏览器合成，若仍无声检查系统音量 |

可复用的技术错误模式统一记录在 [FreqErr.md](FreqErr.md)。

## 15.1 服务端结构

WEB 服务端位于 `backend/` 目录，是本项目的主体：

- **启动方式**：`python -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000`
- **访问方式**：浏览器打开 `http://127.0.0.1:8000`
- **主要功能**：题目录入、AI 解题、组卷、笔记、搜题、批改、画布、专注模式等
- **技术栈**：Python 3.11+、FastAPI、Uvicorn、SQLAlchemy、SQLite、Jinja2、原生 JavaScript/CSS
- **依赖文件**：`backend/requirements.txt`
- **数据目录**：`backend/storage/`
- **错误日志**：`backend/Err.log`

## 15.2 Android 客户端

项目提供 Android 壳应用（`android/` 目录），用于在手机上以原生 App 形式访问运行中的服务器：

- **形态**：WebView 远程壳，不在手机上运行后端；服务器地址在 App 内配置（首次启动进入设置页，或通过右上菜单「服务器设置」修改，连接失败页也提供修改入口）。
- **产物**：项目根目录 `学习搭子-Android.apk`（debug 签名，直接安装；包名 `com.learningagent.app`，要求 Android 7.0+；v1.1 versionCode 2）。
- **能力**：文件上传（图片上传时系统选择器同时提供「拍照直拍」与「相册多选」，非图片导入走默认选择器）、试卷等文件下载（系统下载目录）、摄像头/麦克风授权（专注模式表情分析与语音）、返回键网页后退；局域网 HTTP 地址可用。
- **拍照直拍实现**：`MainActivity.onShowFileChooser` 识别图片类上传（accept 为 image/*），经 `ACTION_CHOOSER` 同时挂载相机与图库 Intent；照片输出到应用私有缓存（`cache/camera/`），经 `androidx.core.content.FileProvider`（authority `com.learningagent.app.fileprovider`，`res/xml/file_paths.xml`）共享；Manifest 声明 `<queries>` 保证 Android 11+ 相机包可见性。
- **App 紧凑模式（省元素）**：WebView UA 追加 `LearningAgentApp/1.1 (Android)` 标记；网页端 base.html 检测 UA 注入 `html.native-app` 类，theme.css §6 提供紧凑规则（压缩卡片/上传区/表格留白、折叠次要说明），上传区文案自动去掉「拖拽」措辞。
- **重新构建**：需要 JDK 17 与 Android SDK（compileSdk 34），在 `android/` 目录执行 `gradle assembleDebug`。构建机 Gradle 8.2 位于 `C:\Gradle\gradle-8.2`（中文路径下 `gradlew.bat` classpath 解析会失败，可用 `java -cp gradle\wrapper\gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain assembleDebug` 替代）。
- **注意**：iOS 用户与手机浏览器用户继续直接访问服务器网址，移动端 Web 适配保持不变（native-app 紧凑规则仅 UA 匹配 App 时生效）；App 内网页密码输入一次后由 WebView localStorage 记住。

## 15.3 桌面端

`desktop/` 目录是**独立副本**的桌面端（PyQt 客户端，信奥/OI 分支为文化课方向），于 2026-09-09 由 `all_projects/学习搭子桌面版`（OISystem）整仓并入，源目录保留不动。

- **与主仓的关系**：代码独立，**`backend/` 与模板/JS 的改动不会自动传导到桌面端**，涉及共享逻辑的改动需单列同步清单。
- **运行时数据**：`desktop/data/`、`desktop/logs/`、`desktop/config/secrets*.json` 永不入库（见 `.gitignore`）。
- **产物**：桌面端 zip 经 `/download` 页提供下载，静态文件挂 `/downloads-desktop/`。
