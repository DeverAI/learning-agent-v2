Q&A

1. 这个系统怎么用？

首先在「API 设置」页面填入 DeepSeek 和 GLM 的 API Key（GLM 使用免费的 GLM-4V-Flash 做 OCR）。然后在「题目本」页面：

步骤 1: 点击上传框选择一张或多张题目图片（支持多选和拖拽）
步骤 2: 图片暂存在右侧列表中，此时尚未处理
步骤 3: 填写解题思路提示（可选）、知识点标签（可选）、年级（可选），选择拆分模式
步骤 4: 点击「开始处理」按钮，AI 才会开始工作

处理完成后，你可以在题目列表中查看。积累一定题目后，进入「组卷中心」，选择组卷方式和筛选条件，AI 会自动从题库中挑选题目并排版成一份完整的试卷。

2. AI 是怎么分工的？

智谱AI GLM (主力) 负责所有需要"看"的任务——上传题目的 OCR 文字识别、判断学科和年级、提取知识点标签、描述题目中的图表内容。使用免费 GLM-4V-Flash 模型。

Kimi (备用) 当 GLM 识别失败时自动回退到 Kimi 进行 OCR 和视觉理解。

DeepSeek 负责所有需要"想"的任务——数学推理、生成详细解答步骤、编写 SVG 示意图代码、试卷排版生成。DeepSeek 擅长逻辑推理和代码生成。

排版审核 多模型协作：先由 DeepSeek 生成试卷 HTML，再由 GLM 进行视觉审核（如有图片渲染环境），最后 DeepSeek 根据意见修复。

3. 数学示意图是怎么生成的？

不是扩散模型（DALL-E/Midjourney）的"猜像素"。系统使用的是 SVG 代码生成：DeepSeek 通过数学计算确定坐标系、曲线上的关键点坐标、几何图形的顶点位置，然后写出精确的 SVG 代码来绘制图形。SVG 是矢量格式，可以无限缩放不模糊。

系统内置三套专用提示词分别处理函数图像、平面几何和统计图表。每张图生成后会自动验证结构完整性，最多重试 2 次。不满意的话，在题目详情页可以点「重新生成」。

4. 组卷有哪些方式？

自定义 Prompt — 完全自由输入你的组卷要求，如"出5道二次函数题，由易到难"。
模拟卷 — 模拟真实考试，按考纲难度分布（基础30%、中档50%、难题20%），含答题卡。
压轴卷 — 高难度训练卷，侧重综合和创新，每题标注难度星级，含完整解题步骤。
专题卷 — 围绕特定知识点组卷，含概念理解、基础应用、综合提高三个层次。

5. 上传时可以填什么？

上传图片时可以填写解题思路提示（"这道题可能要用余弦定理"）、知识点标签（"二次函数,不等式"）和年级。这些是可选的——如果你知道这是什么题，填上能帮 AI 更准确；留空的话 AI 也会自动判断。主要是避免小学题被拿去用四点共圆、大学数学方法去解答。

6. 试卷怎么导出？

HTML: 浏览器打开试卷页面，Ctrl+P 打印，选择 A3 或 A4 纸张，另存为 PDF。KaTeX 会自动渲染所有数学公式。
Word: 直接下载 .docx 文件。公式在 Word 中会以 LaTeX 源码显示。
试卷和答案可以分开下载。

7. 数据存在哪里？

所有数据存储在 backend/storage/ 目录下。SQLite 数据库文件 (app.db) 存储题目和试卷的元数据。每道题的图片、SVG 示意图、HTML 文件都存在以题目 ID 命名的子文件夹中。API Key 保存在 backend/settings.json。整个 storage/ 目录备份即可迁移全部数据。

8. 手机能用吗？

可以。页面已适配移动端：侧边栏在手机上会隐藏为汉堡菜单，表单字段自动换行，表格可以横向滚动。在手机上拍照上传、查看题目、组卷都可以正常使用。

9. 服务器配置要求？

2 核 2G 即可。系统只有一个 Python 进程 + SQLite 数据库，不依赖 Node.js、Redis、MySQL 等外部服务。依赖仅 13 个 Python 包。内存占用通常在 100-300MB 之间。

10. Prompt 积木块怎么用？

在「Prompt 管理」页面编辑模板时，下方有带颜色的变量块（如 {grade}、{subject}）。点击变量块，它会插入到编辑器中光标所在的位置。组卷时这些变量会被自动替换为实际值。你可以修改默认模板、新建自己的模板，也可以随时恢复默认内容。

11. Agent 对话是怎么工作的？

Agent 页面支持多轮对话，有上下文记忆。左侧栏显示所有历史对话，点击 + 创建新对话。

AI 会自动判断你的意图：闲聊用 cheap 模型（快且便宜），解题/推理自动切换 v4-pro 模型，组卷需求会直接带你跳转组卷页面，遇到我还没有的能力也会自动记录到 AGENT_NEEDS.md 待开发。

知识检索

先在本地知识库检索已存内容；本地未命中时可让 GLM 联网搜索补充（需在设置页配置 GLM API Key）。检索到的内容会自动存为知识库文档，可随时查看或删除。
