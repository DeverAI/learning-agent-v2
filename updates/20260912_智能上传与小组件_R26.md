## 1. 智能上传（混页分流）

**痛点**：真实错题本一页常同时有题干、解答、笔记、批注；原先三条独立管线（题目/笔记/试卷）要求学生先自己判断入口。

**实现**：
- `heuristic_classify(ocr_text)`：关键词 + 题号密度 + 「解：」计数 → `question|note|paper|unknown`
- `ai_classify_pages`：视觉模型（MiMo 优先）逐页 JSON 分类，置信度 ≥0.55 才覆盖启发式
- 路由：`route_question` / `route_note` / `route_paper`（试卷会话可续用同一 sid）
- **unknown 不装成功**：按题目处理并提示「请到题库核对」

**API**：
- `GET /api/smart-upload/destinations`
- `POST /api/smart-upload/classify` — 只分类不落库
- `POST /api/smart-upload` — 上传并分流；`dests` 逗号分隔可人工覆盖；`dry_run=true` 演练

**前端**：整卷上传页顶部「智能上传」卡片（选图 → 可选只看分类 → 可改目标 → 上传分流）。
