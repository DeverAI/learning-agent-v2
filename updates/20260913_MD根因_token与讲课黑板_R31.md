## 1. Markdown 展示故障：根因不是渲染代码

**读码 + 线上探测**：

- 前端 `$md` 依赖 `/storage/vendor/marked.min.js` + katex
- **服务器 vendor 目录为空**，本地有 64 个文件 → 线上 **全部 404**
- `$md` 在 marked 未加载时降级为 `<pre>` 转义文本 → 表现为「MD 不能正确展示」

**修**：把本地 `storage/vendor/**` 完整 scp 到服务器；核验 HTTP 200。

## 2. Token 限制（「generation truncated」）

线上 `Err.log`：`AI returned empty response - generation truncated`  
设置里 `deepseek_max_tokens=16384`，而 v4 推理模型 reasoning 会先吃预算。

**修**：

- 默认与页面默认改为 **131072**（与 DeepSeek 上限对齐，不压推理）
- `deepseek_chat(max_tokens=None)` 默认跟 `ds_max_tokens`
- 对话 Agent 去掉写死的 16384
- 服务器 settings 已写入 131072

## 3. 讲课页没有黑板（手机）

**读码**：黑板只在 **专注模式** `focus.html`；`lecture.html` 只有步骤列表，手机上没有主视图板。

**修**：讲课页增加 `lecBoard`（复用 `.board-*` 样式；CSS 已有 768px 下 `min-height:62vh`）；
`highlight()` 把当前步骤 `$md` 写进黑板。
