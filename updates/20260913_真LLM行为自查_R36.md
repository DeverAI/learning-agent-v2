## 真跑测抓到的缺陷（冒烟发现不了）

### 计算器不支持 `;` 多表达式

**日志原文**（真解题调用）：

```
Calculator error for expr '2*sin(radians(90+21.8014))/ (2* sin(radians(21.8014))) ; 1/(2*cos(radians(45)))'
表达式语法错误: invalid syntax
```

模型会一次丢多条式子；`ast.parse(mode="eval")` 对 `a; b` 直接 SyntaxError → 工具白烧 →
后续 JSON 解析失败 → 解题超时。

**修**：`CalculatorSession.evaluate` 按 `;` 拆条，最多 8 条，支持 `prev_result` 链式。
验证：`1+1; 2*3; prev_result+1` → **7**。
