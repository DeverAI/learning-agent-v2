## 1. 错误日志到底说了什么

### 1.1 误导文案

`Err.log` / DB 错误：`AI returned empty response - generation truncated`  

**栈**（app.log，19:24，4 道 pdf_page）：

```
ocr_service.process_image
  -> ai_service.deepseek_solve
    -> _chat_json -> deepseek_json
      -> _extract_json
        raise Exception("... generation truncated")
```

`_extract_json` 在 **`text` 为空** 时就抛这句。**空 ≠ 截断**。  
已改为明确写 `empty response (content is blank...)`。

### 1.2 真实机制（服务器日志原文）

重试时打出：

```
AI empty content + finish_reason=length;
retrying max_tokens=32768 (prev=16384, completion=16383, reasoning=16383)
```

```
retry max_tokens=32768 (prev=16384, completion=16384, reasoning=16384)
```

即：**推理模型把 16384 全烧在 `reasoning_content`，`content` 长度 0**。  
图生成路径 **写死 `max_tokens=16384/8192`**，与 settings 无关。
